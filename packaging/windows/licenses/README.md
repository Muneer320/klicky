# License notice provenance

These notices fill omissions in the published crate archives. They are copied unchanged from the commits recorded in those crates' `.cargo_vcs_info.json`:

- `symphonia-MPL-2.0.txt`: [Symphonia 0.5.5 license](https://github.com/pdeljanov/Symphonia/blob/6d533f26150953a882a6a111ebd13f0abf7129d5/LICENSE), SHA-256 `c76f740d1521b9bed9ca7a04ad526c310493c62621b1341d623b431736533b30`.
- `dasp_sample-MIT.txt`: [dasp_sample 0.11.0 license](https://github.com/RustAudio/sample/blob/97c3bb9b2363c0b46ac1633858bf1054fd02a980/LICENSE-MIT), SHA-256 `b1d6df41ed3aa96806e74c729444d7c121d90e6660a6aed01d298e03fde475a0`.

The portable builder copies other runtime crates' existing notices, the Rust build toolchain's library notices, and checksum-verified source archives for the unchanged MPL-2.0 components. Its inventory identifies exact versions and source locations. A missing notice or unrecognized fallback fails packaging and requires review.
