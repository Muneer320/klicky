A little sound. A little clarity.

Your typing stays on your device.

Klicky plays keyboard sounds locally. There is no Klicky account, cloud service, advertising or analytics in the app.

What happens when you press a key?

Klicky receives keyboard events so it can choose and play a sound while you use other apps. Normal playback does not record your typed text, save a history of keypresses or transmit those events. The Windows app does not access your microphone.

Global input access is sensitive: keyboard events can occur while you enter a password or other private information. Klicky does not need that text, but you should grant input access only to software you trust. On Windows, playback is paused while the desktop is locked or inactive.

The desktop app contains no network client and makes no network requests. It does not send your typing, sound choices or usage statistics to me or to another service.

Settings and custom sounds stay local.

Klicky saves preferences such as the selected sound pack and volume on your device. Custom sound packs remain local files. No account is needed to use them.

Windows manages new Microsoft Store installations in the app's own data area. Repair keeps those settings; Reset clears that app data. If Klicky finds settings or custom sounds from an earlier EXE installation, those existing files can remain in your local Klicky folder after the Store package is removed.

Use Windows Settings to repair, reset or remove a Store installation. For other installation methods, the removal guide explains how to keep settings or remove them with --purge. Back up custom sounds you want to keep before clearing app data.

Diagnostics are something you choose.

The Windows diagnostics command reports aggregate counters and local app state, including volume, sound-pack name and process identifiers. It does not include key names, typed text or microphone recordings. Nothing is uploaded automatically; share reports only if you choose to.

Developer tools and other platforms have their own diagnostic modes. In particular, Linux benchmark mode can log mapped key names and timing. Do not run that mode while entering passwords or other sensitive text. See the security policy for platform details.

Visiting the website and downloading Klicky.

This site has no analytics scripts, advertising trackers or account system. Sound previews play only when you choose them, and the site does not listen to global keyboard input.

GitHub Pages hosts this site, and GitHub hosts the source and direct downloads. Those services receive normal web-request information, such as your IP address, under GitHub's privacy statement. Install helpers and package managers contact their download services to install or update the app.

Microsoft handles Store downloads, account information and platform diagnostics under Microsoft's privacy statement. Klicky is free. Opening external support or project links takes you to the relevant site's own privacy policy.

Questions or concerns?

For a privacy question, open an issue without including private information. For a vulnerability or possible keystroke exposure, use GitHub's private reporting form instead.

This policy will be updated here if Klicky's data handling changes. The public history records those changes.
