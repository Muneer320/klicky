01 / Under the keycap

Less work between
press and playback.

Decode once. Prepare the samples. Keep the audio device open. Klicky moves the expensive work out of the keypress path.

  1. 01 → INPUTCapture the press

    Linux uses evdev below Wayland and X11. macOS uses global event taps through rdev, plus a media-key tap.

  2. 02 → DAEMONMap the event

    The input thread maps the key name and sends a timestamped event to the daemon.

  3. 03 → PCM CACHEFind its sound

    Look up decoded, normalized PCM slices. Shared sample buffers are reused across keypresses.

  4. 04 → OUTPUTMix it in

    A persistent Rodio mixer plays overlapping sounds through the OS audio backend.

CLI → local Unix socket → daemon controls · User service manager → daemon lifecycle

The input path is event-driven; the daemon drains channels with a 500 μs sleep. Audio initialization tries 256, 512, then 1024-frame buffers before fallback. Read the architecture →

04 / Put it on your keyboard

Pick your platform.
Keep your keyboard.

Linux/Omarchy and macOS have both been physically tested. Windows is unsupported. The newest macOS crash-recovery policy still awaits real launchd validation.

Linux / released packages

Install the published build.

Arch x86_64 and Debian-compatible amd64 packages are available in v0.3.0. Debian-compatible systems can also use the signed APT repository below. 

# After installing the package
systemctl --user enable --now klicky.service

Release ≠ current source. Published v0.3.0 has no klicky service subcommand. Use systemctl --user. Both binaries currently report 0.3.0; check klicky --help.

Linux package instructions →

Prefer the latest code? Build from source.

macOS / current source

Build it for your Mac.

Requires Rust 1.87+ and Xcode Command Line Tools. There is no downloadable signed or notarized macOS application. 

git clone https://github.com/Muneer320/klicky.git
cd klicky
./scripts/install-macos.sh

The installer puts Klicky at ~/.local/bin/klicky and enables a login LaunchAgent. Grant that installed binary Accessibility access in System Settings.

A small tool. A clear boundary.

Your typing stays local.

Klicky observes global keyboard events. Normal mode does not store typed text or log key names; the daemon makes no network requests. Benchmark mode prints mapped key names. Use it only outside sensitive input.
