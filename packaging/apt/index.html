02 / Make yourself at home

A small setup.
A daily companion.

Choose your system, copy its command, and follow the installer. Your settings and custom packs stay yours when you update.

01Windows Windows 11 · x64 · unsigned preview

Run in PowerShell. The helper checks the published installer's SHA-256 file and opens the setup wizard. No Rust or Visual Studio needed. 

irm https://klicky.muneer320.tech/install.ps1 | iex

The command becomes available when the public Windows preview is published. Until then, the Windows guide links to the current build artifacts. GitHub artifact downloads require signing in.

Choose your login-startup preference in setup. Open Klicky from Start and choose Resume from the tray. The helper starts the installed app automatically when setup finishes. A paused launch selected in the wizard is respected. The menu also changes packs and volume.

Published downloads ↗Portable and manual options
02macOS Source installer + optional menu bar control

Run in Terminal. Setup prepares missing Rust and Apple build tools, then builds and installs Klicky with the menu bar control. Approve Apple's tools dialog if shown; first setup takes a few minutes. 

curl -fsSL https://klicky.muneer320.tech/install.sh | bash

Setup starts the app and enables login startup. If Accessibility permission is needed, it opens System Settings → Privacy & Security → Accessibility and shows ~/.local/bin/klicky in Finder. Add that file with +; setup retries while you approve it. No second Terminal command is needed.

To skip the menu bar helper, add -s -- --no-menu after bash.

Manual setup, updates and removal ↗
03Linux Ubuntu / Debian · Arch / Omarchy · source

On Ubuntu 24.04+ / compatible Debian amd64, or Arch / Omarchy x86_64, run: 

curl -fsSL https://klicky.muneer320.tech/install.sh | bash

The installer selects the signed APT repository or Arch package, checks its key or checksum, and enables the user service. Run as your desktop user; it asks for sudo for package setup. Use a terminal with curl; setup installs GnuPG if needed. Compatible Omarchy shells get the bar toggle by default; add -s -- --no-omarchy-toggle after bash to skip it.

Other distributions and architectures can use the same source installer after installing Rust and ALSA development headers. Wayland and X11 are supported; automatic setup uses systemd and udev.

04 / A few good questions

Before you ask.

Do I need a mechanical keyboard?

No. Klicky adds the sound in software. A laptop keyboard or ordinary desktop keyboard works too.

Does it record what I type?

Normal operation reads key events locally to trigger sound. It does not store typed text, log key names, or send network requests. Advanced Linux/macOS benchmark mode prints mapped key names for controlled tests. Privacy details.

Will the sound keep up with my typing?

Samples are prepared when the pack loads and played through a persistent mixer. Output-device delay still matters: try laptop speakers or wired headphones if Bluetooth feels out of sync. Internal dispatch measurements are not physical key-to-speaker latency. How performance is measured.

Can I add my own sounds?

Yes. Put a custom pack in your user sounds folder. A pack with the same name takes priority over the bundled copy. Pack format and examples.

How do I update or remove it?

Run a newer Windows installer, use your Linux package manager, or rerun the source installer. Stop the Linux service before replacing its package. Your settings and custom packs are kept. Update and removal commands.

Something is not working. Where do I start?

Check the selected output, pack, volume and pause state. The troubleshooting guide covers permissions, startup and missing sounds. If needed, open an issue with your OS, build and what happened.
