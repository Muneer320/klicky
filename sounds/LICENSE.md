# Klicky sound recordings

Copyright (c) 2026 Muneer Alam and Sauhard Gupta

The keyboard recordings and timing maps in this directory were created specifically for the original Klicky project. Muneer Alam performed the keypress recordings on a physical mechanical keyboard during the original development with Sauhard Gupta.

These audio assets are distributed under the MIT License in the repository root. The license applies to the recordings, timing maps, and sound-pack metadata in this directory.

The pack names describe recording profiles rather than endorsements by switch or keyboard manufacturers. No manufacturer audio was copied for these packs.

When redistributing a pack, retain this notice and the repository MIT License.
